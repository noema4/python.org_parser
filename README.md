# ✨ Парсер Python.org
Привет! Это мой первый парсинг-проект, где я достал заголовки с сайта python.org.
Все данные были сохранены в CSV файл, который потом можно будет открыть в Excel или LibreOffice.

Этот инструмент автоматически собирает актуальные новости с официального сайта Python и сохраняет их в структурированном виде. Это избавляет от необходимости вручную мониторить сайт — вы всегда видите свежие данные в удобном формате.

🛠 Технологии
    Python 3 — основной язык.
    requests — для HTTP-запросов.
    BeautifulSoup4 — для парсинга HTML.
    csv — для сохранения данных.
